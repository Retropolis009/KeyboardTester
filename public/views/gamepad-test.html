How to Test Controller Stick Drift Online

A browser-based gamepad tester online reads the HTML5 Gamepad API directly, which surfaces the exact normalized axis values the operating system sends to games. Stick drift appears as a non-zero resting radius: the plotter dot sits away from center even with your thumbs off the controller. Set the controller down on a flat surface, wait a few seconds for the baseline to settle, then read the drift percentage for each stick.

Potentiometer sticks typically begin drifting after 200–600 hours because carbon tracks wear where the wiper rests during idle menus. Hall-effect sticks are immune to mechanical wear but can still report drift when a magnet shifts or a firmware calibration table is lost.

Deadzones, Triggers & the Rumble Test

Games apply a radial deadzone — commonly 0.10 to 0.20 — before treating stick input as intentional. The toggle above applies a 0.08 deadzone to the plots so you can see whether your drift would be masked by a typical in-game deadzone or whether it would leak through. Analog triggers should sweep smoothly from 0% to 100% with no dead zones at either end; a trigger that jumps from 0% to 40% needs cleaning or recalibration. The rumble button fires both the low-frequency and high-frequency actuators through the Gamepad Haptics actuator API where the browser and driver expose it.

Buttons, Mapping & Compatibility Notes

The button matrix labels every reported index, so a controller that maps A to index 0 versus index 1 is immediately visible — useful when comparing a "standard mapping" Xbox pad to an unbranded DirectInput pad. PlayStation pads expose Cross/Circle/Square/Triangle as B/A/Y/X respectively. If nothing lights up, press a button on the controller first; browsers withhold gamepad data until a user gesture unlocks it.
