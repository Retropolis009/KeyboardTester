How to Run an Accurate Keyboard Chatter Test

To run a reliable keyboard chatter test, type natural paragraphs for two minutes or tap suspect switches 40–50 times at a normal cadence without holding keys into OS auto-repeat. Because this profiler ignores operating-system repeat events and measures the exact keyup-to-keydown gap with high-precision browser clocks, genuine switch contact bounce stands out immediately below a 35 millisecond threshold.

Start with the default 35 ms window, which sits just above the fastest human double-taps, then tighten toward 20 ms if you want to grade a switch that is only beginning to fail. Every scan code keeps its own fastest interval, average interval, and actuation count, so a single failing leaf stands out from the healthy keys around it.

Reading the Bounce Verdict Column

Clean means every repeat interval sits comfortably above the threshold. Marginal marks keys whose fastest repeat approaches the window — often a switch that will begin double-typing within weeks. Chatter marks a switch already producing phantom actuations and needs cleaning with contact spray, a firmware debounce bump, or a hot-swap replacement.
