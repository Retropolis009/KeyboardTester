How to Run a Dead Pixel Check on Any Monitor

A monitor test online works because dead-pixel inspection only requires large, uniform fields of pure red, green, blue, black, and white. Clean the screen first — dust specks are the most common false positive — then display each solid colour fullscreen and scan in a slow raster pattern. A dead subpixel stays dark on red, green, and blue; a stuck subpixel stays lit on black.

Count the defects before contacting the manufacturer. Most warranties require three to five defective subpixels within the central zone, and some panel classes tolerate zero bright pixels but several dark ones. Photograph the screen at full brightness with the panel showing each solid colour so a support agent can verify the count.

Measuring True Refresh Rate and Frame Pacing

Advertised refresh rates are a maximum, not a guarantee. This bench timestamps consecutive requestAnimationFrame callbacks and reports both the median interval and the observed Hz. A 144 Hz panel should land near 6.94 ms per frame; a result stuck at 16.67 ms usually means the browser is capped at 60 Hz, the display cable is running an older HDMI mode, or Windows is set to 60 Hz in Display Settings.

Frame pacing is the variance, not the average. Consistent 6.94 ms intervals feel smooth even at lower rates; alternating 6 ms and 12 ms intervals at the same average feel stuttery. If the timeline shows regular tall bars, close background GPU consumers — a browser compositor thread or a screen recorder is often the culprit.

Contrast, Gamma & Colour Banding Checks

The 16-step greyscale ramp should show sixteen distinct blocks. If the two darkest blocks merge, black crush is hiding shadow detail; if the two lightest merge, highlights are clipping. The colour ramp exposes dithering quality — a 6-bit panel with frame-rate control will show subtle noise, while a poorly implemented 6-bit panel shows hard bands.
